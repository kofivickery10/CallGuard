What changed, and why

Try this first

The New / Today switch

Top right. It swaps only custom properties — but now spacing as well as colour: page padding, card padding, card gaps, row height, control height, radii, shadows and the type scale. Same markup, same components. It shows that “airy” is a set of numbers, not a rebuild.

Airiness is space and elevation, not colour

Card padding 16 → 24px, gaps 12 → 20, table rows 40 → 52, controls 34 → 40, radii 10 → 14. Borders got lighter and shadows took over the job of separating surfaces. A hard 1px border on every edge is what made the old screens feel like a spreadsheet.

Stat cards are the way in, not decoration

The top row answers “what needs me?” rather than “how are we doing?” — and each card is a button that opens that queue pre-filtered. A tile you can't act on is a poster.

Home starts with a worklist, not a dashboard

“Start here” is ordered by risk then age, so the first row is genuinely the next thing to do. Charts moved below it: useful monthly, not at 9am.

One hub instead of eleven settings pages

Everything you configure once lives behind Set up as a grid of cards, each with a description so you don't have to guess. Click Integrations: it drills in with a breadcrumb back rather than spending a page transition on a leaf you'll leave in twenty seconds. The URL still changes, so it stays linkable.

Sixteen nav items down to seven

Home, Review, Sales, Calls, Customers, Insights, Set up. Review carries a live count, because a number on a nav item is the cheapest findability there is. The five separate “where are the problems” pages became one queue.

The workbench stays dense — deliberately

Browsing surfaces should be airy. A tool someone uses for six hours should not be: more white space there means more scrolling and less evidence on screen. So the workbench gets the calmer borders and the bigger type, but keeps its two bound panes and its density. Airy is a property of the right screens, not all of them.

Page height still doesn't follow the data

Checkpoints and transcript scroll independently inside the viewport. Click any checkpoint: the transcript jumps to its quote and the dock playhead moves with it. A 47-minute sale and a 4-minute one produce the same page.

Every colour is still measured

All text clears 4.5:1 on every surface it sits on, in both themes. Green means passed and nothing else — the brand is ink, so a green element can only ever be a verdict. Pass, fail and review each carry an icon and a word, because red/amber/green cannot be separated for a deuteranopic reader.

Prototype. Names and figures are invented; the design system is the real proposal.
